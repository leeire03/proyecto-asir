Documentación del proyecto de PIMA(1º ASIR)

Proyecto ASIR - Multitienda
La empresa es una multitienda dedicada a la venta de diferentes tipos de productos, como alimentos, productos de limpieza, higiene personal, artículos para el hogar y gestión de paquetes.
Su actividad principal es ofrecer una gran variedad de productos a los clientes en un mismo establecimiento. Para ello, realiza pedidos a proveedores, organiza la mercancía, controla las existencias y gestiona las ventas.
